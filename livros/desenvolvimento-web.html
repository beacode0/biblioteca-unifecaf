MATERIAL DE ESTUDO

Desenvolvimento Web

Autor: Carlos Oliveira

Este material apresenta os fundamentos do desenvolvimento web, mostrando como HTML e CSS são utilizados para criar páginas organizadas, responsivas e acessíveis.

🎯 Objetivos de aprendizagem

Ao estudar este material, você deverá compreender os principais elementos utilizados na criação de páginas web e entender como organizar uma interface de forma clara para os usuários.

  • Entender o funcionamento básico de uma página web.
  • Conhecer a estrutura de um documento HTML.
  • Utilizar elementos HTML de forma organizada.
  • Compreender a função do CSS.
  • Aplicar cores, fontes e espaçamentos.
  • Compreender o conceito de responsividade.
  • Conhecer práticas básicas de acessibilidade.

01 O que é desenvolvimento web?

Desenvolvimento web é o processo de criação de sites e aplicações que podem ser acessados por meio de um navegador.

Uma página web pode apresentar textos, imagens, links, formulários, menus e diferentes tipos de conteúdo.

Como uma página chega ao usuário?

Quando uma pessoa acessa um site, o navegador interpreta os arquivos da página e apresenta seu conteúdo na tela. Os principais recursos utilizados na construção de páginas simples são HTML e CSS.

💡 Dica: Antes de pensar apenas na aparência de um site, é importante organizar seu conteúdo e definir o que o usuário precisa encontrar na página.

02 HTML: estrutura da página

HTML significa HyperText Markup Language. Ele é utilizado para estruturar o conteúdo de uma página web.

Por meio do HTML podemos indicar títulos, parágrafos, listas, links, imagens, tabelas, formulários e outras informações.

Exemplo simples

Elemento Função
<h1> Representa um título principal.
<p> Representa um parágrafo.
<a> Cria um link.
<ul> Cria uma lista não ordenada.
📌 Lembrete: HTML organiza o conteúdo. Ele não deve ser confundido com a parte visual da página.

03 CSS: aparência e apresentação

CSS significa Cascading Style Sheets. Ele é utilizado para controlar a apresentação visual dos elementos HTML.

Com CSS podemos definir cores, fontes, tamanhos, margens, espaçamentos, bordas e diferentes características visuais.

Aplicação prática

Na Biblioteca UniFECAF, o HTML organiza os títulos, textos, livros e links. Já o CSS define as cores, os cartões dos livros, os espaçamentos e a organização visual da página.

💡 Dica: Uma boa organização entre HTML e CSS facilita a manutenção do projeto e permite alterar o visual sem modificar todo o conteúdo da página.

04 Estrutura e organização

Um site organizado deve possuir uma estrutura clara de arquivos. Separar HTML, CSS e imagens ajuda a manter o projeto mais fácil de entender.

Exemplo de organização

Pasta/arquivo Função
index.html Página principal.
css/style.css Arquivo responsável pelos estilos.
livros/ Armazena as páginas dos materiais.
assets/imagens/ Armazena imagens utilizadas no projeto.
📌 Lembrete: Uma boa estrutura de pastas ajuda a localizar os arquivos e facilita futuras alterações no projeto.

05 Links e navegação

Os links permitem que o usuário navegue entre diferentes páginas de um site.

No HTML, normalmente utilizamos o elemento <a> para criar links.

Exemplo prático

Na Biblioteca UniFECAF, o botão "Ver detalhes" direciona o estudante para uma página específica do material.

Dessa forma, a página inicial apresenta os livros disponíveis e cada material pode possuir uma página própria com conteúdos mais completos.

06 Formulários

Formulários permitem que o usuário forneça informações para uma página ou sistema.

Eles podem ser utilizados em pesquisas, cadastros, contatos, buscas e diferentes tipos de interação.

Exemplo na biblioteca

O campo de pesquisa da Biblioteca UniFECAF é um exemplo de formulário. O estudante pode digitar o nome de um livro para procurar um conteúdo.

💡 Dica: Os campos de um formulário devem possuir textos claros para ajudar o usuário a entender o que precisa ser preenchido.

07 Responsividade

Responsividade significa adaptar uma página para diferentes tamanhos de tela.

Um site pode ser acessado por computadores, notebooks, tablets e celulares. Por isso, seus elementos precisam se adaptar para manter a leitura e a navegação confortáveis.

Aplicação prática

Na Biblioteca UniFECAF, os cartões de livros e as seções da página são reorganizados quando a tela fica menor. Assim, o conteúdo continua acessível também pelo celular.

⚠️ Atenção: Uma página que funciona apenas em uma tela grande pode prejudicar a experiência de usuários que acessam o site pelo celular.

08 Acessibilidade

A acessibilidade busca permitir que diferentes pessoas consigam utilizar um site e compreender seus conteúdos.

Alguns cuidados importantes

  • Utilizar textos claros e fáceis de compreender.
  • Manter contraste adequado entre texto e fundo.
  • Utilizar títulos para organizar o conteúdo.
  • Fornecer textos alternativos para imagens importantes.
  • Garantir que os links tenham uma função clara.
  • Evitar elementos muito pequenos ou difíceis de clicar.
📌 Lembrete: Acessibilidade não é apenas uma questão visual. A organização e a clareza das informações também influenciam a experiência de diferentes usuários.

09 Aplicação prática

Imagine que você precise criar uma página para uma biblioteca acadêmica.

Primeiro, você pode utilizar HTML para criar o cabeçalho, menu, título, textos, cartões de livros e links.

Depois, utiliza CSS para definir a identidade visual, organizar os elementos e adaptar a página para diferentes tamanhos de tela.

O resultado é uma interface que combina estrutura, apresentação visual, navegação e facilidade de uso.
