#  Biblioteca Digital UniFECAF

## 1. Sobre o projeto

A Biblioteca Digital UniFECAF é um projeto desenvolvido para a disciplina de Design Web, com o objetivo de criar uma interface simples, organizada e responsiva para apresentar materiais de estudo de uma biblioteca digital.

A ideia surgiu da necessidade de facilitar a visualização dos livros, a identificação das categorias e o acesso às informações disponíveis. Para isso, desenvolvi um site com navegação intuitiva, cores suaves e páginas organizadas para tornar a experiência do usuário mais agradável.

O projeto foi desenvolvido utilizando **HTML e CSS**, colocando em prática os conhecimentos de estruturação de páginas, estilização, responsividade e organização de arquivos.

## 2. Objetivos do projeto

* Criar uma interface para uma biblioteca digital.
* Facilitar a localização e a visualização dos materiais de estudo.
* Organizar os conteúdos por livros, categorias e serviços.
* Desenvolver páginas com navegação simples.
* Adaptar a interface para computadores e telas menores.
* Praticar os conceitos de HTML e CSS.
* Publicar o site na internet utilizando o GitHub Pages.

## 3. Tecnologias utilizadas

* **HTML5:** utilizado para estruturar as páginas e organizar os conteúdos.
* **CSS3:** utilizado para definir as cores, os espaçamentos, os cartões, os botões e a responsividade.
* **Git:** utilizado para registrar as versões do projeto.
* **GitHub:** utilizado para armazenar e compartilhar os arquivos.
* **GitHub Pages:** utilizado para publicar o site na internet.

## 4. Como o site funciona

A página inicial apresenta o nome da biblioteca, um menu de navegação, uma apresentação do projeto e as principais seções do site.

### Início

Apresenta a biblioteca e permite que o usuário comece a explorar os materiais disponíveis.

### Livros

Apresenta seis materiais de estudo em cartões, com título, autor, descrição e categoria. Cada livro possui um link para uma página própria.

### Páginas dos livros

Cada material possui uma página com conteúdos divididos em módulos, explicações, exemplos, atividades de fixação e resumos para ajudar na compreensão dos assuntos.

Os seis materiais disponíveis são:

1. Introdução à Tecnologia.
2. Desenvolvimento Web.
3. Gestão e Administração.
4. Fundamentos do Design.
5. Educação e Aprendizagem.
6. Gestão de Projetos.

### Categorias

Apresenta categorias para facilitar a identificação dos assuntos, como Tecnologia, Administração, Design e Educação.

### Serviços

Apresenta informações sobre busca de livros, acesso digital e apoio aos estudantes.

### Navegação

O menu permite acessar as principais seções da página inicial. Nas páginas dos livros, existem links para retornar à lista de materiais ou à página inicial.

O campo de pesquisa da página inicial é visual e ainda não realiza uma busca automática nos livros.

## 5. Identidade visual

A interface utiliza tons de verde combinados com branco e cores neutras claras. Essa combinação foi escolhida para transmitir uma sensação de organização, tranquilidade e acolhimento, adequada a um ambiente de estudos.

A fonte Arial foi utilizada por ser simples e legível. Os cartões, os títulos e os botões ajudam a organizar as informações e facilitam a navegação.

## 6. Responsividade e acessibilidade

O CSS possui regras de responsividade para adaptar a disposição dos elementos de acordo com a largura da tela.

Também foram utilizadas estruturas semânticas do HTML, indicação do idioma português do Brasil e um recurso para pular diretamente ao conteúdo principal.

Essas decisões contribuem para a organização, a legibilidade e a navegação do site.

## 7. Organização dos arquivos

A estrutura do projeto está organizada da seguinte maneira:

```text
biblioteca-unifecaf/
├── index.html
├── css/
│   └── style.css
├── assets/
│   └── imagens/
└── livros/
    ├── tecnologia.html
    ├── desenvolvimento-web.html
    ├── gestao-administracao.html
    ├── fundamentos-design.html
    ├── educacao-aprendizagem.html
    └── gestao-projetos.html
```

### Função de cada pasta e arquivo

* `index.html`: página inicial da biblioteca.
* `css/style.css`: estilos utilizados nas páginas.
* `assets/imagens/`: pasta destinada aos recursos visuais.
* `livros/`: contém as páginas individuais dos materiais de estudo.

## 8. Ordem de desenvolvimento

O desenvolvimento foi realizado seguindo uma sequência para facilitar a organização e os testes.

1. **Planejamento:** análise da proposta e definição dos objetivos da biblioteca.
2. **Estrutura HTML:** criação da página inicial, do menu e das seções principais.
3. **Estilização CSS:** definição das cores, da tipografia, dos cartões e dos botões.
4. **Criação dos livros:** desenvolvimento das seis páginas individuais com conteúdos organizados por módulos.
5. **Navegação:** configuração dos links entre a página inicial e as páginas dos livros.
6. **Responsividade:** criação de regras CSS para adaptar o layout a telas menores.
7. **Testes:** verificação dos links, dos botões e da apresentação visual.
8. **Versionamento:** utilização do Git para registrar o projeto e envio dos arquivos ao GitHub.
9. **Publicação:** configuração do GitHub Pages para disponibilizar o site na internet.

## 9. Como executar o projeto

Como o projeto utiliza HTML e CSS, não é necessário instalar frameworks ou configurar um servidor para visualizar as páginas localmente.

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. Navegue pelas seções e pelos links dos livros.

Para editar o projeto, recomenda-se utilizar um editor de código, como o Visual Studio Code.
